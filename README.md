# GeoSiteKit

Site officiel de GeoSiteKit : de la donnée au projet.

Cette première version est un site statique publié avec GitHub Pages.

## Structure

- `index.html` : page d'accueil
- `styles.css` : mise en page responsive
- `script.js` : navigation mobile et année du pied de page
- `assets/` : identité visuelle et image principale
