Installation

Installer GeoSiteKit en quatre étapes.

Le parcours ci-dessous sera disponible avec l’installateur Setup signé. Il ne nécessite pas d’installation manuelle de composants dans AutoCAD.

  1. 01

    Télécharger l’installateur

    Enregistrez le fichier Setup publié pour votre version de GeoSiteKit.

  2. 02

    Fermer AutoCAD puis lancer Setup

    Fermez les sessions AutoCAD en cours, puis exécutez le fichier Setup téléchargé.

  3. 03

    Terminer l’installation

    Suivez les étapes proposées par Setup. L’installation prépare l’application et son intégration AutoCAD pour votre session Windows.

  4. 04

    Ouvrir AutoCAD et GeoSiteKit

    Rouvrez AutoCAD, ouvrez votre dessin puis lancez GeoSiteKit depuis son interface intégrée.

Service informatique

Informations de validation

Une fiche technique sera proposée avec une publication signée. Elle précisera notamment la version, l’éditeur et la signature, l’empreinte SHA-256, les emplacements d’installation, les besoins réseau, les mises à jour, la désinstallation et les données locales.

Pourquoi cette fiche n’est-elle pas encore disponible ?

Elle doit correspondre exactement au paquet réellement publié et signé. Aucun document de validation ni lien de téléchargement n’est affiché avant cette publication.

Assistant

Choix et confidentialité

Après l’installation, l’onglet Support offre une aide locale sans clé. Vous choisissez explicitement le mode utilisé : aide locale, IA externe avec votre clé personnelle Gemini API, OpenAI API ou Anthropic API, ou modèle local hors ligne. La clé API est conservée quand vous changez de mode et seul son bouton de suppression l’efface. Un modèle local facultatif se télécharge seulement à votre demande, n’est pas inclus dans l’installateur et son téléchargement ne l’active pas automatiquement. La recherche Web est une option explicite de Gemini API : ses sources sont affichées et elle ne lance jamais une action dans GeoSiteKit.
