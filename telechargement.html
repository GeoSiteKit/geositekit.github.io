Installation

Quatre étapes, sans droits administrateur.

GeoSiteKit copie tous ses composants dans votre profil Windows et prépare automatiquement la commande dans AutoCAD.

  1. 01

    Télécharger le ZIP

    Cliquez sur le bouton ci-dessus pour récupérer la dernière bêta depuis le dépôt officiel GeoSiteKit.

  2. 02

    Extraire tous les fichiers

    Dans l'Explorateur Windows, faites un clic droit sur le ZIP puis choisissez Extraire tout. Ne lancez pas l'application directement depuis l'archive compressée.

  3. 03

    Installer GeoSiteKit

    Fermez AutoCAD, ouvrez le dossier extrait GEOSITEKIT_APP, puis double-cliquez sur GeoSiteKit.exe. L'installation se fait uniquement pour votre compte Windows.

  4. 04

    Lancer GeoSiteKit dans AutoCAD

    Redémarrez AutoCAD, ouvrez un dessin enregistré puis saisissez GEOSITEKIT. Aucun chargement manuel avec APPLOAD n'est nécessaire.

À savoir

Version bêta.

Cette méthode a été testée sous Windows avec Microsoft Defender et un compte sans droits administrateur. Une politique informatique d'entreprise différente peut néanmoins imposer ses propres restrictions.

Si vous avez réellement installé la version MSI 1.7.1, désinstallez-la d'abord dans les paramètres Windows avant d'utiliser cette version ZIP.
