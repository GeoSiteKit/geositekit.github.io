Télécharger GeoSiteKit

L'installateur configure GeoSiteKit et son intégration AutoCAD automatiquement pour votre compte Windows, sans droits administrateur.

Télécharger la dernière version
Version stable Installateur MSI · Windows 64 bits

Le téléchargement démarre automatiquement depuis GitHub.

Installation

Trois étapes, sans droits administrateur.

Le MSI installe tous les composants dans votre profil Windows et prépare automatiquement la commande GeoSiteKit dans AutoCAD.

  1. 01

    Télécharger le MSI

    Cliquez sur le bouton ci-dessus pour récupérer la dernière version depuis le dépôt officiel GeoSiteKit.

  2. 02

    Lancer l'installation

    Double-cliquez sur le fichier GeoSiteKit-v1.7.1-win64.msi. L'installation se fait uniquement pour votre compte et ne demande pas de droits administrateur.

  3. 03

    Lancer GeoSiteKit dans AutoCAD

    Redémarrez AutoCAD, ouvrez un dessin enregistré puis saisissez GEOSITEKIT. Aucun chargement manuel avec APPLOAD n'est nécessaire.

À savoir

Sécurité Windows.

L'installateur ne demande pas de droits administrateur. Comme cette première version MSI n'est pas encore signée, Windows ou la politique de votre entreprise peut toutefois afficher ou bloquer un avertissement de réputation avant son lancement.
