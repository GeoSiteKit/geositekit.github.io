L’approche GeoSiteKit

Le terrain avant le tracé.

Pensé par un architecte paysagiste, pour les architectes paysagistes.

Une préparation, pas une décision à votre place

Le projet commence par comprendre ce qui est déjà là.

GeoSiteKit rassemble dans AutoCAD les informations utiles pour situer une parcelle, cadrer une emprise et préparer une lecture de terrain. L’outil organise les données disponibles ; il ne remplace ni le regard, ni le diagnostic, ni la conception de l’architecte paysagiste.

01

Des sources éparses à une lecture de site

Cadastre, orthophoto, relief, végétation et bâti arrivent rarement sous une forme immédiatement lisible dans le dessin. GeoSiteKit les met en relation autour d’une même emprise et d’une logique de calques.

02

Une base pour le projet paysager

La base préparée aide à lire les contraintes, les continuités et les potentiels du site. Elle soutient les échanges et l’avant-projet, sans imposer de réponse graphique.

03

Un parcours maîtrisé

Les six modules géographiques se complètent dans l’application. Quatre automatisations livrées prolongent cette lecture par des représentations spécifiques lorsque le projet le demande.
